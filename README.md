# Dhanya Shetty | Personal Portfolio

A responsive personal portfolio website developed as part of the YR NOVATECH Full Stack Development Internship Task 2.

## About the Project

This portfolio website presents my education, technical skills, projects, interests, and contact information in a clean and responsive design.

The website is designed to provide recruiters and visitors with an overview of my technical background and practical project experience.

## Features

- Responsive navigation bar
- Hero section with introduction and call-to-action buttons
- About Me section
- Technical Skills section
- Projects gallery
- Contact form
- JavaScript form validation
- Responsive design for desktop, tablet, and mobile devices
- GitHub links for projects
- Smooth navigation between sections

## Technologies Used

- HTML5
- CSS3
- JavaScript

Approach

The portfolio was developed using HTML5 for the structure, CSS3 for styling and responsive layouts, and JavaScript for contact form validation and interaction.

CSS media queries were used to make the website responsive across desktop, tablet, and mobile screen sizes.

The website follows a simple and organized structure so that visitors can easily navigate between the About, Skills, Projects, and Contact sections.

Responsive Design

The website is designed to adapt to different screen sizes and provides a mobile-friendly layout.
